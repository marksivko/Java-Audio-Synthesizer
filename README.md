# Java Audio Synthesizer
A lightweight desktop synthesizer application built in Java. It features an interactive 88-key piano interface, customizable waveform generation, an audio delay, and a waveform visualizer.

## Running the Application
1. Download the latest `java-synthesizer.jar` from the [Releases](https://github.com/marksivko/pno/releases/) page.
2. Open the `.jar` file, or run it from your terminal:
   ```bash
   java -jar java-synthesizer.jar
